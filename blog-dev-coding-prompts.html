개발자를 위한 AI 코딩 프롬프트 모음

코드 리뷰부터 버그 수정까지, 실전에서 바로 쓰는 프롬프트 모음.

BLACKBOXY 팀 약 6분

AI 코딩 도구를 쓸 때 가장 자주 반복하는 작업들을 프롬프트로 정리했습니다. 그대로 복사해서 상황에 맞게 조금씩 수정해서 써보세요.

코드 리뷰

시니어 개발자 관점으로 이 코드를 리뷰해줘. 가독성 → 성능 → 보안 순서로 이슈를 정리하고, 각 이슈마다 수정된 코드 예시를 보여줘.

버그 원인 분석

아래 코드에서 [증상]이 발생해. 재현 조건은 [조건]이야. 가능한 원인을 우선순위대로 나열하고, 각각 어떻게 검증할 수 있는지 알려줘.

레거시 코드 이해하기

이 코드가 무슨 일을 하는지 한 줄씩 주석으로 설명해줘. 특히 왜 이런 방식으로 짰는지 추측할 수 있으면 같이 적어줘.

테스트 코드 생성

이 함수에 대한 단위 테스트를 작성해줘. 정상 케이스, 경계값, 예외 케이스를 모두 포함해서.

성능 최적화

이 함수의 시간 복잡도를 분석하고, 개선 가능한 부분이 있다면 이유와 함께 최적화된 코드를 제안해줘.

API 설계 리뷰

이 REST API 설계를 리뷰해줘. RESTful 원칙에 맞는지, 네이밍이 일관적인지, 에러 응답 형식이 적절한지 확인해줘.

커밋 메시지 작성

아래 diff를 보고 컨벤셔널 커밋 형식으로 커밋 메시지를 작성해줘. (feat/fix/refactor 등)

기술 부채 정리

이 파일에서 기술 부채로 볼 수 있는 부분을 찾아서 심각도와 함께 리스트로 정리해줘.
💡 팁: 코딩 프롬프트는 "무엇을 고칠지"보다 "어떤 기준으로 판단할지"를 명시할 때 결과물의 품질이 크게 달라집니다. 자세한 작성법은 Cursor 프롬프트 가이드에서 확인하세요.
