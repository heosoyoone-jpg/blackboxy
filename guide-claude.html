Claude 프롬프트 구조 설계법

긴 문서, 복잡한 논리, 정확한 맥락 전달에 강한 Claude를 제대로 쓰는 법.

Prompt Guide 약 6분

Claude는 긴 문서를 통째로 이해하고, 복잡한 지시사항을 논리적으로 따라가는 데 강점이 있습니다. 이 강점을 살리려면 프롬프트를 구조적으로 정리해서 전달하는 게 중요합니다.

1. 맥락(Context)을 먼저, 지시는 나중에

Claude는 배경 정보를 충분히 주면 그만큼 정확하게 답합니다. "이거 요약해줘"보다 어떤 목적으로, 누구에게 보여줄 요약인지부터 설명하는 게 좋습니다.

예시
아래는 우리 팀의 3분기 마케팅 회의록이야. 이걸 경영진에게 보고할 3줄 요약으로 만들어줘. 경영진은 숫자와 다음 액션만 궁금해해. [회의록 본문]

2. XML 태그로 구획을 나누세요

Claude는 <document>, <instructions> 같은 태그로 프롬프트 안의 영역을 나눠주면 각 부분을 더 정확히 구분해서 처리합니다. 특히 여러 문서를 동시에 주거나, 문서와 지시사항을 헷갈리지 않게 하고 싶을 때 유용합니다.

예시
<document> (여기에 원본 문서) </document> <instructions> 위 문서에서 숫자로 된 성과 지표만 뽑아서 표로 정리해줘. </instructions>

3. 단계별로 생각하도록 유도하세요

복잡한 분석이나 판단이 필요한 작업이라면 "단계별로 생각한 다음 결론을 내려줘"라는 문장을 추가해보세요. Claude는 이렇게 사고 과정을 거치도록 유도했을 때 더 정확한 결론에 도달하는 경향이 있습니다.

4. 원하는 답변의 길이와 톤을 명시하세요

Claude는 별다른 지시가 없으면 꽤 상세하게 답하는 편입니다. 짧고 간결한 답을 원한다면 "3문장 이내로", "불릿포인트로 5개만" 처럼 분량을 구체적으로 제한해주세요.

실전 팁: 반대 관점도 요청하기

중요한 의사결정에 관한 질문이라면 "네 생각과 반대되는 관점도 하나 제시해줘"라고 요청해보세요. Claude는 균형 잡힌 시각을 제공하는 데 능숙하며, 이렇게 물으면 놓치기 쉬운 리스크를 짚어주는 경우가 많습니다.

예시
이 사업 계획의 장점을 분석해줘. 그리고 내가 놓치고 있을 만한 반대 관점이나 리스크도 하나 짚어줘.

5. 결과물의 형식을 예시로 보여주기

보고서, 이메일, 코드 주석처럼 정형화된 결과물이 필요하다면 원하는 형식의 짧은 예시를 하나 붙여주세요. 특히 사내 문서 양식처럼 특수한 형식을 맞춰야 할 때 효과적입니다.

💡 정리: 맥락을 충분히 → 필요하면 XML 태그로 구획 정리 → 단계적 사고 유도 → 분량·톤 명시. Claude는 "무엇을, 왜" 설명해줄수록 정확해집니다.
