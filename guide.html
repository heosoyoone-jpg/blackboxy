AI별 프롬프트 작성 가이드

ChatGPT, Claude, Midjourney, Cursor, Gemini — 도구마다 잘 먹히는 프롬프트 방식이 다릅니다.

같은 목적이라도 AI마다 반응하는 방식이 다릅니다. 어떤 모델은 역할극(롤플레이) 지시에 강하고, 어떤 모델은 구조화된 조건 나열에 더 잘 반응합니다. 아래 가이드에서 각 AI별로 실전에서 바로 쓸 수 있는 프롬프트 작성법을 정리했어요.

프롬프트를 직접 만들기 어렵다면 Prompt Packs를 둘러보세요.

🟢 ChatGPT
ChatGPT 프롬프트 잘 쓰는 법
역할 지정, 단계별 지시, 출력 형식 고정까지 — GPT 계열 모델에서 안정적인 결과를 뽑는 구조
 🟠 Claude
Claude 프롬프트 구조 설계법
긴 문서 처리와 논리적 추론에 강한 Claude에게 맥락을 정확히 전달하는 프롬프트 구성
 🟡 Midjourney
Midjourney 프롬프트 공식
피사체 → 스타일 → 조명 → 카메라 → 파라미터 순서로 쌓는 이미지 프롬프트 작성 공식
 🔵 Cursor
Cursor 프롬프트 실전 예시
코드베이스 맥락을 활용한 지시, 리팩토링 요청, 버그 수정 프롬프트까지
 🟣 Gemini
Gemini 활용법
