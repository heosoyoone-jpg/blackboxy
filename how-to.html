1. 프롬프트 저장하는 방법

홈 화면 검색창 아래에 있는 📥 주워담기 버튼을 누르면 저장 창이 뜹니다. 제목, 프롬프트 내용, 서랍(카테고리), 태그, 출처를 입력할 수 있어요.

  • 제목: 나중에 알아볼 수 있는 짧은 이름 (예: "만능 분석가 프롬프트")
  • 프롬프트 내용: 실제로 복사해서 쓸 전문. 여기에 붙여넣은 텍스트가 그대로 "꺼내쓰기" 버튼으로 복사돼요
  • 서랍: AI 만능 / 코딩 / 디자인 / 마케팅 / 이미지 / 비즈니스 중 하나를 고르면 카드 색상이 자동으로 정해집니다
  • 출처: 인터넷에서 발견한 프롬프트라면 어디서 가져왔는지(reddit.com 등) 적어두면 나중에 원문을 찾기 쉬워요. 직접 쓴 프롬프트는 비워두면 "✏️ 내가 씀"으로 표시됩니다
💡 팁: 저장은 브라우저의 로컬 저장소(localStorage)에 이루어집니다. 즉, 별도 회원가입 없이 바로 쓸 수 있지만, 같은 브라우저·같은 기기에서만 데이터가 유지돼요.

2. 태그 활용법

서랍이 큰 분류라면, 태그는 세부 분류입니다. 예를 들어 "코딩" 서랍 안에서도 #리팩토링, #버그, #React 같은 태그로 더 잘게 나눌 수 있어요.

태그는 저장할 때 쉼표로 구분해서 여러 개 입력할 수 있고, 검색창에 태그 이름만 입력해도 관련 프롬프트가 바로 필터링됩니다.

  • 태그는 동사보다 명사로 짓는 게 나중에 찾기 편해요 (예: "정리해줘" ❌ → "리팩토링" ⭕)
  • 너무 세분화하지 마세요. 3~5개 정도의 태그를 자주 재사용하는 게 검색에 유리합니다

3. AI별 프롬프트 관리하기

같은 목적이라도 ChatGPT, Claude, Gemini, Midjourney는 프롬프트 작성 방식이 조금씩 다릅니다. BLACKBOXY에서는 이걸 태그로 구분하는 걸 추천해요.

예시 태그 조합
제목: 블로그 초안 생성기 서랍: 마케팅 태그: #GPT, #블로그, #SEO

이렇게 저장해두면 "이 프롬프트, Claude로 옮기면 어떻게 써야 하지?" 싶을 때 원본을 참고해서 톤만 조정하면 됩니다. AI 이름 자체를 태그로 쓰는 게 나중에 도구를 바꿀 때도 헷갈리지 않는 방법이에요.

4. 검색 팁

홈 화면 상단의 큰 검색창은 제목, 본문, 태그를 한 번에 검색합니다. ⌘ K (또는 Ctrl K) 단축키로 바로 검색창에 포커스를 줄 수 있어요.

  • 정확한 제목이 기억나지 않으면 핵심 키워드 한 단어만 쳐보세요 (예: "SEO", "리팩토링")
  • 서랍 필터와 검색을 같이 쓰면 범위가 좁혀져서 더 빠르게 찾을 수 있어요
  • 상단의 색색 서랍 아이콘을 클릭하면 해당 서랍의 프롬프트만 볼 수 있습니다

5. 백업하는 방법

현재 BLACKBOXY는 브라우저 로컬 저장소를 사용하기 때문에, 브라우저 데이터를 지우거나 다른 기기로 옮기면 저장된 프롬프트에 접근할 수 없게 됩니다. 중요한 프롬프트는 아래 방법으로 별도 백업해두는 걸 권장해요.

  1. 즐겨찾기(⭐)로 표시해둔 프롬프트는 우선적으로 별도 문서에 복사해두기
  2. 브라우저 개발자 도구(F12) → Application → Local Storage에서 blackbox_memories_v1 키 값을 복사해 텍스트 파일로 보관
  3. 추후 클라우드 동기화 기능이 추가되면 자동 백업으로 전환 예정입니다
