개인정보처리방침

최종 수정일: 2026년 9월 27일

BLACKBOXY(이하 "서비스")는 이용자의 개인정보를 소중히 다루며, 아래와 같은 원칙에 따라 최소한의 정보만을 처리합니다.

1. 수집하는 정보

이 방침은 BLACKBOXY 웹사이트와 BLACKBOXY Chrome 확장프로그램에 적용됩니다. 확장프로그램에 관한 내용은 5번 항목에 정리했습니다.

BLACKBOXY는 별도의 회원가입 절차 없이 이용 가능한 서비스입니다. 이용자가 저장하는 프롬프트, 태그, 서랍 분류 등의 데이터는 이용자의 브라우저 로컬 저장소(localStorage)에만 저장되며, 서비스 운영자의 서버로 전송되거나 저장되지 않습니다.

즉, BLACKBOXY는 이용자가 어떤 프롬프트를 저장했는지 알 수 없으며, 해당 데이터에 접근할 수 없습니다.

2. 자동으로 수집되는 정보

현재 BLACKBOXY는 별도의 방문 통계(애널리틱스) 도구나 광고 쿠키를 사용하지 않으며, 서비스 운영자가 직접 쿠키를 설정하지 않습니다.

다만 웹사이트를 불러오는 과정에서 아래 외부 서비스가 기술적으로 필요한 정보를 처리할 수 있습니다.

제공자처리될 수 있는 정보목적
Netlify (웹 호스팅)IP 주소, 브라우저 정보, 접속 시각 등 접속 기록웹사이트 제공 및 보안
Google Fonts, jsDelivr (글꼴 제공)IP 주소, 브라우저 정보화면 글꼴 불러오기

위 정보는 각 제공자의 개인정보 처리방침에 따라 처리되며, 서비스 운영자가 이를 이용해 이용자를 식별하지 않습니다.

3. 광고 및 분석 도구

현재 서비스에는 광고(Google AdSense 등)나 방문 분석 도구(Google Analytics 등)가 적용되어 있지 않습니다. 추후 이러한 도구를 도입하는 경우, 적용 전에 본 방침에 수집 항목과 목적, 쿠키 사용 여부 및 거부 방법을 추가해 안내하겠습니다.

4. 정보의 보관 및 삭제

BLACKBOXY에 저장된 프롬프트 데이터는 전적으로 이용자의 브라우저에 저장되므로, 브라우저 데이터(캐시/저장소)를 삭제하면 즉시 함께 삭제됩니다. 서비스 운영자가 별도로 보관하는 이용자 콘텐츠는 없습니다.

유료 프롬프트팩 결제는 외부 결제 페이지에서 진행되며, 결제 과정에서 입력하는 정보는 해당 결제 서비스의 개인정보처리방침에 따라 처리됩니다. BLACKBOXY 웹사이트는 결제 정보를 직접 받거나 저장하지 않습니다.

5. BLACKBOXY Chrome 확장프로그램

BLACKBOXY Chrome 확장프로그램(이하 "확장프로그램")은 ChatGPT, Claude, Gemini를 사용하다가 프롬프트를 바로 저장할 수 있게 돕는 도구입니다. 확장프로그램도 로그인이나 회원가입 없이 동작합니다.

처리하는 정보

확장프로그램은 이용자가 직접 저장한 아래 정보만 처리합니다.

  • 이용자가 직접 선택한 텍스트, 또는 AI 입력창에 작성한 프롬프트
  • 프롬프트 제목과 본문
  • 태그, 서랍(분류)
  • 즐겨찾기 여부, 복사 횟수, 저장·수정 날짜
  • 출처(ChatGPT·Claude·Gemini)와 저장한 페이지의 주소

언제 처리하나요

선택한 텍스트나 AI 입력창 내용은 이용자가 저장 동작을 실행한 경우에만 BLACKBOXY 저장 대상으로 처리됩니다. 즉, 우클릭 메뉴의 BLACKBOXY에 저장이나 현재 입력 저장을 누른 뒤, 저장 창에서 저장을 눌렀을 때만 저장됩니다. 확장프로그램은 대화 내용이나 입력 내용을 자동으로 읽거나 모으지 않습니다.

확장프로그램 창을 열면, 현재 탭이 ChatGPT·Claude·Gemini인지 표시하기 위해 탭의 주소를 확인합니다. 이 주소는 이용자가 프롬프트를 저장할 때 출처로 함께 기록되는 경우를 제외하고는 저장되지 않습니다.

어디에 저장되나요

BLACKBOXY Chrome Extension은 사용자가 직접 저장한 프롬프트 데이터를 브라우저의 로컬 저장공간(chrome.storage.local)에 저장합니다. 저장 데이터는 사용자의 브라우저 환경에 보관됩니다.

BLACKBOXY는 해당 프롬프트 내용을 자체 서버로 전송하거나 저장하지 않습니다. 확장프로그램에는 BLACKBOXY 서버로 데이터를 보내는 기능이 없으며, 광고·분석 도구도 포함되어 있지 않습니다.

우클릭 저장 창을 페이지 안에 띄울 수 없는 경우에는, 작은 저장 창으로 선택한 텍스트를 넘기기 위해 브라우저의 임시 저장공간(chrome.storage.session)을 잠깐 사용하며, 창이 열리면 바로 지웁니다.

백업 파일

이용자가 백업 파일 저장을 누르면 저장된 프롬프트가 JSON 파일로 이용자의 기기에 내려받아집니다. 이 파일은 이용자가 직접 관리하며, BLACKBOXY로 전송되지 않습니다.

삭제

확장프로그램 안에서 프롬프트를 삭제하면 해당 기록이 지워집니다. 확장프로그램을 삭제하면 확장프로그램에 저장된 데이터도 브라우저에서 함께 삭제되므로, 필요한 경우 먼저 백업 파일을 저장해 주세요.

ChatGPT · Claude · Gemini 서비스

ChatGPT(OpenAI), Claude(Anthropic), Gemini(Google)에서 이용자가 입력하고 주고받는 내용은 각 서비스의 개인정보처리방침에 따라 처리됩니다. BLACKBOXY는 이들 서비스와 제휴 관계가 없으며, 이들 서비스의 개인정보 처리에 관여하지 않습니다.

6. 제3자 제공

서비스는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 웹사이트와 확장프로그램에서 이용자가 저장한 프롬프트는 이용자가 직접 백업 파일로 내려받는 경우를 제외하고 이용자의 브라우저 밖으로 전송되지 않습니다.
