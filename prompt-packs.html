업무에 바로 쓸 수 있는 프롬프트를 목적별로 모았어요. 필요한 팩을 골라 한 번에 서랍에 담아보세요.

🧺 처음이라면 부터 서랍에 담아보세요. 결제 없이 바로 써볼 수 있어요.

프롬프트팩 둘러보기

프롬프트팩은 이렇게 써요

  1. 팩 파일 받기무료팩은 바로, 유료팩은 결제 후 JSON 파일을 받아요.
  2. 데이터 관리 열기BLACKBOXY 홈의 내 기억 보관함 옆 🗂 데이터 관리를 눌러요.
  3. 프롬프트팩 가져오기🧺 프롬프트팩 가져오기를 누르고 받은 JSON 파일을 골라요.
  4. 내 서랍에 추가지금 있는 기억은 그대로 두고, 팩의 프롬프트만 서랍에 더해져요.
🗄 내 기억 보관함 열기

구매 전 자주 묻는 질문

구매하면 어떻게 받나요?

결제가 완료되면 JSON 프롬프트팩 다운로드 링크가 제공됩니다.

JSON 파일은 어떻게 사용하나요?

BLACKBOXY 홈에서 🗂 데이터 관리 → 🧺 프롬프트팩 가져오기를 누르고 파일을 선택하면 됩니다. 무료 스타터팩은 이 페이지에서 내 서랍에 바로 담기로도 추가할 수 있어요.

기존 프롬프트가 사라지나요?

아니요. Prompt Pack은 기존 데이터에 추가만 됩니다. 이미 저장한 기억을 바꾸거나 지우지 않아요.

같은 팩을 두 번 가져오면 어떻게 되나요?

이미 추가한 팩이면 먼저 알려드려요. 그래도 다시 가져오면 같은 프롬프트가 한 번 더 들어갑니다.

다른 기기에서도 사용할 수 있나요?

현재 BLACKBOXY는 브라우저에 저장하는 방식이라, 받은 JSON 파일을 다른 기기로 옮겨 같은 방법으로 가져오면 됩니다.

환불은 어떻게 하나요?

환불 및 결제 정책은 결제 페이지에서 확인할 수 있습니다.
